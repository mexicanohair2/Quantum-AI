# Quantum-AI

**Quantum-AI — самостоятельный проект интеллектуальной системы.** Внешние языковые модели в текущей версии не подключены.

## Интерфейс

Публичная страница: https://mexicanohair2.github.io/Quantum-AI/

Сейчас опубликован мобильный интерфейс чата в фирменной бордово-фиолетовой теме. История переписки хранится локально в браузере.

## Собственное ядро

Планируемая архитектура описана в [документе проекта](docs/QUANTUM_AI_ARCHITECTURE.md):

- Byte-level BPE-токенизатор;
- собственная decoder-only Transformer-модель на PyTorch: RMSNorm, GQA, SwiGLU и causal attention;
- генерация с top-k / top-p и потоковой выдачей;
- обучение и сохранение checkpoint;
- отдельные модули памяти, ограниченного reasoning, поиска и обработки изображений.

**Важный статус:** архитектурные решения и тестовые замечания сохранены, но полноценные исходники модели, обученные веса и проверенный inference-процесс пока не восстановлены в этом репозитории. Поэтому интерфейс не подменяет Quantum-AI ответами сторонней модели и честно показывает, что ядро ещё в разработке.

## Проверка текущей версии

- Интерфейс не загружает сторонний challenge-виджет.
- Запросы не передаются сторонней языковой модели.
- API пока возвращает состояние «ядро не подключено», а не имитирует ответ ИИ.
- История чата хранится в браузере пользователя.
