# Quantum-AI

**Quantum-AI** — отдельный исследовательский проект собственной языковой модели и её программной системы.

> Важно о текущем состоянии: в этот репозиторий перенесены доступные в истории проекта технические сведения и зафиксированные решения. Полные исходные файлы DeepSeek из старых сообщений не удалось извлечь как самостоятельные файлы, поэтому здесь не создаются фиктивные реализации модулей и не заявляется, что модель уже обучена или запускается.

## Сайт проекта

https://mexicanohair2.github.io/Quantum-AI/

## Что зафиксировано

- Byte-level BPE-токенизатор: special token IDs 0–4, byte IDs 5–260, BPE IDs начиная с 261.
- Transformer с RMSNorm, GQA, SwiGLU и causal attention через `scaled_dot_product_attention`.
- Генерация с top-k/top-p, repetition penalty, streaming и инкрементальным UTF-8-декодированием.
- Контур обучения с scheduler, checkpoint и resume.
- SQLite-память с изоляцией по `user_id`.
- AST-ограниченный reasoning и веб-поиск с SSRF-защитой.
- Экспериментальные направления vision и тестирования.

Подробности, известные ограничения и замечания к проверкам: [docs/DEEPSEEK_TRANSFER.md](docs/DEEPSEEK_TRANSFER.md).
