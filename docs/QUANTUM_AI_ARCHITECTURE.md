# Quantum-AI — актуальная архитектура и статус

**Обновлено:** 22 ноября 2026 года  
**Целевая архитектура:** только ONLINE. Локальная генерация на телефоне больше не является продуктовым направлением.

## 1. Продуктовые правила

- Название и публичная идентичность продукта — **Quantum-AI**.
- В пользовательском интерфейсе не показывать названия базовых моделей, загрузчики моделей и технические параметры.
- Технические сведения о сторонних компонентах и лицензиях сохранять в необходимых служебных документах и уведомлениях.
- Приложение работает как онлайн-клиент: интерфейс на GitHub Pages, генерация на удалённом сервере.
- Целевые ограничения: бесплатно, без платных API, подписок, оплаты сервера, платёжных карт и API-ключей, которые пользователь должен получать или настраивать.
- Не обещать неограниченный бесплатный доступ при наличии квот, очередей или ограничений.
- Не помещать секреты в клиентский JavaScript или публичный репозиторий.
- Не смешивать проект с QQCross.

## 2. Текущее состояние интерфейса

- Из пользовательского интерфейса удалён запрос на скачивание локальной модели.
- Удалены видимые упоминания базовой модели и локального режима.
- Файл src/app.js больше не импортирует quantum-engine.js и не запускает локальную генерацию.
- История диалога и её экспорт остаются доступны.
- Онлайн-бэкенд ещё не подключён; поле ввода отключено, а интерфейс прямо сообщает, что подключение настраивается.
- Старый src/quantum-engine.js оставлен как неиспользуемый legacy-прототип. Он не должен автоматически запускаться или отображаться в пользовательском интерфейсе.

## 3. Кандидат бесплатного онлайн-хостинга

Hugging Face Spaces ZeroGPU — только кандидат для исследования. Бесплатные аккаунты имеют дневные GPU-квоты; есть очередь и ограничения доступности. Это не гарантированный неограниченный backend.

Официальные документы:
- https://huggingface.co/docs/hub/spaces-zerogpu
- https://huggingface.co/docs/hub/spaces-overview
- https://huggingface.co/pricing

До интеграции проверить:
1. Совместимость выбранного runtime и модели.
2. Вызов из браузера по HTTPS и требования к авторизации.
3. Дневные квоты, очереди, холодный старт и остановку Space.
4. Отсутствие платежей и обязательной банковской карты.
5. Безопасность и приватность пользовательских запросов.

Не подключать неизвестный публичный Space как постоянный backend без проверки владельца, кода и условий.

## 4. Целевая схема

Браузер → GitHub Pages frontend → HTTPS → удалённый inference backend → ответ/поток → интерфейс Quantum-AI.

История, память, поиск, файлы, изображения и голос — отдельные модули с понятными потоками данных и политикой приватности. При недоступности сервера показывать реальную ошибку, не подменять её фиктивным ответом.

## 5. Release gate

Приложение можно называть онлайн-работающим только после end-to-end теста с опубликованного сайта: запрос действительно доходит до удалённого движка и ответ возвращается без платного ключа или скрытого биллинга. Квоты и ограничения должны быть видны пользователю.
