# Quantum-AI — архитектура и статус

**Обновлено:** 22 ноября 2026 года  
**Целевая архитектура:** онлайн-клиент, удалённый сервис генерации, интерфейс в стилистике QQCross.

## 1. Продуктовые правила

- Название и публичная идентичность — **Quantum-AI**.
- В пользовательском интерфейсе не показывать названия базовых моделей, загрузчики моделей и технические параметры.
- Сведения о лицензиях сторонних компонентов сохранять в необходимых служебных документах.
- Интерфейс работает онлайн; локальная генерация на телефоне не является целью.
- Целевые ограничения: бесплатно, без платных API, подписок, оплаты сервера, платёжных карт и ключей, которые пользователь должен получать или настраивать.
- Не обещать неограниченный доступ при наличии квот или очередей.
- Не помещать секреты в клиентский JavaScript или публичный репозиторий.
- Не смешивать Quantum-AI с QQCross.

## 2. Интерфейс

- Бордово-фиолетовая палитра и мягкие градиенты согласованы с визуальным направлением QQCross.
- На широком экране боковая панель закреплена слева; на телефоне выезжает как drawer.
- История диалогов поддерживает создание, переключение, фильтрацию по названию и содержимому, переименование, удаление и экспорт текущего разговора.
- История хранится в localStorage текущего браузера и не синхронизируется между устройствами.
- Старый формат единственного диалога мигрируется в новый список чатов без удаления исходной записи.
- Пользовательский интерфейс не содержит запроса на скачивание локальной модели или видимых названий модели.

## 3. Общий веб-поиск

- Отдельная вкладка «Поиск в интернете» выполняет поиск по общему веб-индексу и отображает список страниц, домены, сниппеты и ссылки на первоисточники.
- Провайдер: Tavily Search API в anonymous keyless режиме через POST /search с заголовком X-Tavily-Access-Mode: keyless.
- Официальный JavaScript SDK Tavily документирует Search и Extract без API-ключа, с общей ограниченной квотой; Crawl, Map и Research требуют ключ. Общая квота не является гарантированным ресурсом.
- Поисковый запрос отправляется внешнему поисковому провайдеру. Это показывается в интерфейсе.
- При временном лимите или ошибке показывается понятное сообщение и возможность открыть запрос во внешнем поисковике.
- Поиск не обещает проиндексировать весь существующий интернет: результаты зависят от индекса и доступности провайдера.

## 4. Состояние AI backend

- Онлайн-инференс backend ещё не подключён.
- Отправка сообщений в чат остаётся отключённой: интерфейс не должен имитировать ответ и выдавать его за настоящий ИИ.
- Отдельный поиск по интернету работает независимо от inference backend.
- Следующий технический этап — безопасный бесплатный удалённый inference endpoint без секретов в публичном frontend.

## 5. Release gate

Перед заявлением о полной готовности требуются:
1. Browser-тест истории чатов: создание, открытие, фильтр, переименование, удаление, восстановление после перезагрузки и миграция старой истории.
2. Реальный тест веб-поиска из браузера Android, включая CORS, 429/rate limit, нулевой результат и fallback-ссылку.
3. End-to-end тест удалённого AI backend с опубликованного сайта.
